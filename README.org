* Programming Notes
:PROPERTIES:
:CUSTOM_ID: programming-notes
:END:
A collection of personal notes on programming languages and computer
science fundamentals.

These notes are working material maintained while studying and
revisiting technical topics. They are incomplete and will change over
time. They are not official language documentation, a complete
curriculum, or a definitive reference.

every directory has a README or a complete sequence of notes.

** Format
:PROPERTIES:
:CUSTOM_ID: format
:END:
The notes are primarily written in [[https://orgmode.org/][Org mode]] as
=.org= files. They are plain text; Emacs with Org mode provides support
for navigating outlines, internal links, and source blocks.

** Status and accuracy
:PROPERTIES:
:CUSTOM_ID: status-and-accuracy
:END:
The material is revised and expanded as the project develops. Topics may
be missing, incomplete, or awaiting review. Examples may depend on a
particular compiler, runtime, platform, or language version. Check
individual notes for any stated verification details, and consult
authoritative references when correctness or version-specific behavior
matters.
