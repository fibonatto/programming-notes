#+title: C++ Data Structures
#+startup: showall

* C++ Data Structures
The standard library supplies containers with value semantics: copying a container copies its elements, and destroying it destroys them.

** 1. Arrays
#+begin_src cpp
#include <array>

int raw[3] = {1, 2, 3};                  // C array: decays to a pointer, no size info
std::array<int, 3> a = {1, 2, 3};        // fixed size, knows its size, no decay
a.size();                                // 3
a.at(5);                                 // throws std::out_of_range
a[5];                                    // undefined behavior (no check)
#+end_src

Prefer =std::array= to C arrays when the size is fixed at compile time.

** 2. std::vector
The default sequence container: contiguous storage, amortized O(1) =push_back=.

#+begin_src cpp
#include <vector>

std::vector<int> v = {3, 1, 2};
v.push_back(4);
v.emplace_back(5);               // constructs in place
v.reserve(100);                  // allocate capacity, size unchanged
v.size();  v.capacity();

for (int x : v) { }
for (auto &x : v) { x *= 2; }
#+end_src

Growth may reallocate: any pointer, reference, or iterator into the vector is invalidated. Inserting or erasing in the middle invalidates the ones after that point. =std::vector<bool>= is a bit-packed specialization whose =operator[]= returns a proxy, not a =bool &=.

** 3. Strings
#+begin_src cpp
std::string s = "hello";
s += " world";
s.substr(0, 5);                        // "hello"
s.find("lo");                          // index or std::string::npos

void f(std::string_view sv);           // non-owning, no copy
#+end_src

A =string_view= must not outlive the characters it refers to, and it is not guaranteed to be null-terminated. =std::string= holds bytes; it knows nothing about Unicode.

** 4. Ordered and hashed associative containers
#+begin_src cpp
#include <map>
#include <set>
#include <unordered_map>
#include <unordered_set>

std::map<std::string, int> ordered;          // red-black tree, sorted by key, O(log n)
std::unordered_map<std::string, int> hashed; // hash table, average O(1)

hashed["a"] = 1;                      // operator[] inserts a default value if missing
if (auto it = hashed.find("b"); it != hashed.end()) { /* found */ }
hashed.contains("a");                 // C++20
hashed.at("zzz");                     // throws std::out_of_range

for (const auto &[key, value] : hashed) { }   // structured bindings
#+end_src

- Use =std::map= when you need sorted iteration or range queries.
- Iteration order of =unordered_map= is unspecified.
- A custom key type needs ~operator==~ and a =std::hash= specialization for the unordered containers, or =operator<= (or a comparator) for the ordered ones.
- =std::set= and =std::unordered_set= store keys only.

** 5. Other containers
| Container                  | Properties                                              |
|----------------------------+---------------------------------------------------------|
| =std::deque=               | Fast insertion at both ends, non-contiguous             |
| =std::list=                | Doubly linked; stable iterators; rarely the right choice|
| =std::forward_list=        | Singly linked                                           |
| =std::stack=, =std::queue= | Adapters over =deque= (or another container)            |
| =std::priority_queue=      | Binary heap; largest element on top by default          |
| =std::span<T>= (C++20)     | Non-owning view of a contiguous range                   |

Linked lists have poor cache behavior; benchmark before preferring them to =vector=.

** 6. Structs and classes
#+begin_src cpp
struct Point {
    double x = 0;
    double y = 0;
};

Point p{1.0, 2.0};
Point q{.x = 1.0, .y = 2.0};          // C++20 designated initializers (declaration order)
auto [x, y] = p;                      // structured binding
bool same = (p.x == q.x);
#+end_src

A =struct= with only public members and no user-provided constructors is an /aggregate/ and supports brace initialization. Equality and ordering are not generated automatically; C++20 can generate them:

#+begin_src cpp
struct Point {
    double x, y;
    auto operator<=>(const Point &) const = default;   // also gives ==
};
#+end_src

** 7. Pairs and tuples
#+begin_src cpp
#include <tuple>
#include <utility>

std::pair<std::string, int> p{"a", 1};
p.first;  p.second;

std::tuple<int, double, std::string> t{1, 2.0, "x"};
std::get<0>(t);
auto [a, b, c] = t;
#+end_src

Prefer a named =struct= to a tuple when the fields have meaning.

** 8. optional and variant
=std::optional<T>= is "a =T= or nothing". =std::variant= is a type-safe tagged union, the closest thing to a sum type.

#+begin_src cpp
#include <optional>
#include <variant>

std::optional<int> find_id(std::string_view name);
if (auto id = find_id("ada")) { use(*id); }
find_id("x").value_or(-1);

struct Circle { double r; };
struct Rect   { double w, h; };
using Shape = std::variant<Circle, Rect>;

template <class... Ts> struct overloaded : Ts... { using Ts::operator()...; };
template <class... Ts> overloaded(Ts...) -> overloaded<Ts...>;   // needed before C++20

double area(const Shape &s) {
    return std::visit(overloaded{
        [](const Circle &c) { return 3.14159265358979 * c.r * c.r; },
        [](const Rect &r)   { return r.w * r.h; },
    }, s);
}
#+end_src

=std::visit= fails to compile if a case is missing, so it is checked for exhaustiveness. =std::get<T>(v)= throws =std::bad_variant_access= on the wrong alternative; =std::get_if<T>(&v)= returns a pointer or null.

** 9. Enums
#+begin_src cpp
enum class Color { Red, Green, Blue };

Color c = Color::Green;
int n = static_cast<int>(c);       // explicit conversion required
#+end_src

Prefer =enum class= (scoped, no implicit conversion to int) over the C-style =enum=.

** 10. Ownership inside containers
#+begin_src cpp
std::vector<std::unique_ptr<Shape>> shapes;      // owns polymorphic objects
shapes.push_back(std::make_unique<Circle>(1.0));

std::vector<Widget *> view;                      // non-owning: OK if you know the lifetimes
#+end_src

Copying a =vector<unique_ptr<T>>= is a compile error; move it. Do not store raw pointers in a container if they are meant to own.

** 11. Choose the structure for the job
| Need                                  | Common choice                         |
|---------------------------------------+---------------------------------------|
| Growable sequence (default)           | =std::vector=                         |
| Fixed-size sequence                   | =std::array=                          |
| Key-value lookup                      | =std::unordered_map=                  |
| Sorted keys, range queries            | =std::map=                            |
| Membership test                       | =std::unordered_set=                  |
| Fixed named fields                    | =struct=                              |
| One of several types                  | =std::variant=                        |
| Value that may be absent              | =std::optional=                       |
| View over existing data               | =std::span=, =std::string_view=       |
| Polymorphic objects                   | =std::unique_ptr<Base>= in a container|

Start with =vector=, =string=, =unordered_map=, and plain structs. Change when profiling or the problem says to.
